# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue. On the affected repository, open the **Security** tab and choose **Report a vulnerability**. If you are not sure which repository is affected, report it on [foundation](https://github.com/Polycentric-Commonwealth/foundation/security/advisories/new).

Include what you found, how to reproduce it and what an attacker could do with it. We will acknowledge your report within a week and keep you informed until it is resolved. We are glad to credit you in the advisory unless you prefer otherwise.

## Scope

Everything in this organization is in scope, including the protocol specifications: a flaw in a specification matters more than a flaw in any one implementation.

The software is an early draft and is not yet used with real people's data. Please do not test against instances you do not run yourself.
