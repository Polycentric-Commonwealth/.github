# Polycentric Commonwealth

An open design for world governance with power divided so thoroughly that no person, party or country can seize it, and open-source software that lets anyone check that it works as promised.

- **Four layers with fixed powers:** the Commonwealth (global), Regions, States and Localities. Each can do only what its charter lists.
- **An equal dividend for every person,** paid from fees on what nobody made: land, minerals, the atmosphere and the radio spectrum.
- **Trust you can check:** every official act is a signed record in a witnessed public ledger, counts that move money are audited by random sample, and no layer above a State holds a list of people.

New here? Read the [ten-minute explainer](https://github.com/Polycentric-Commonwealth/foundation/blob/main/docs/explainer.md).

## Repositories

| Repository | What it holds | Status |
| --- | --- | --- |
| [foundation](https://github.com/Polycentric-Commonwealth/foundation) | The design, the protocol specifications every platform speaks, the decision records and the shared Go library | Draft specifications with working implementations |
| [platform-state](https://github.com/Polycentric-Commonwealth/platform-state) | The State platform: residents' register, the dividend cycle, audits, officials and the public ledger | Working; deployable for testing |
| [platform-commonwealth](https://github.com/Polycentric-Commonwealth/platform-commonwealth) | The Commonwealth platform: Commons Fund, dividend settlement, Audit Office and attestation | Not started |
| [platform-region](https://github.com/Polycentric-Commonwealth/platform-region) | The Region platform: shared infrastructure, environment and appeals | Not started |
| [platform-locality](https://github.com/Polycentric-Commonwealth/platform-locality) | The Locality platform: council, budgets and services for cities and towns | Not started |

Everything is early and has not had an independent security review. Do not use it with real people's data yet.

## Get involved

Specification review, cryptography and security review, Go, design and accessibility, policy and translation are all welcome. See [contributing](https://github.com/Polycentric-Commonwealth/foundation/blob/main/CONTRIBUTING.md), or open an issue in any repository. Organizations interested in a pilot can describe what they have in mind in an issue in [foundation](https://github.com/Polycentric-Commonwealth/foundation/issues).
